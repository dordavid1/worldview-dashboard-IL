# worldview-dashboard-IL
Global tactical live dashboard

## Projects

* **WorldView** (`index.html`) — global tactical live dashboard.
* **[WayinStudio](video/)** (`video/`) — browser-native AI video studio: on-device Whisper
  transcription in any language, translation into any other language (NLLB-200), reading the
  subtitle track already embedded in a video file, bilingual live captions, TextRank summaries,
  ranked auto-clips, moment search, auto-reframing and subtitle/clip export.
  Serve over HTTP and open `/video/`.
